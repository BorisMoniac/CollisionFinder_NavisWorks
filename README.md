# НашеПО · Коллизии для Топоматик 360

Версия 0.5.0. Плагин открывает HTML/XML-отчёты Navisworks, показывает коллизии в нижней горизонтальной панели и создаёт знаки проблемных участков в 3D по координатам отчёта. Рабочие состояния, назначения, комментарии и снимки сохраняются только в переносимой сессии по команде пользователя.

Сопоставление объектов отчёта с IFC/SMDX и собственный поиск пересечений запланированы на следующий этап.

## Установка в Топоматик 360

[**Установить плагин**](https://360.topomatic.ru/?extensionInstallPath=https%3A%2F%2Fborismoniac.github.io%2FCollisionFinder_NavisWorks%2F)

Ссылка открывает Топоматик 360 сразу в разделе установки плагинов. Подтвердите подключение, затем откройте нижнюю вкладку **Коллизии**. При первом запуске панель будет пустой: загрузите отчёт или откройте ранее сохранённую сессию.

## Быстрый локальный запуск

1. Дважды нажмите **Запустить локально.cmd**.
2. Откроются локальный просмотрщик и Топоматик 360 с подключённым плагином.
3. Если Топоматик запросит разрешение, подтвердите подключение.
4. Откройте нижнюю вкладку **Коллизии**.
5. Нажмите **Открыть отчёт** и выберите HTML/XML Navisworks.
6. Если снимки хранятся отдельно, нажмите **Снимки** и укажите их папку.

Адреса после запуска:

- [Локальный просмотрщик](http://localhost:4173/preview.html)
- [Топоматик 360 с локальным плагином](https://360.topomatic.ru/?extensionDevelopmentPath=http%3A%2F%2Flocalhost%3A9091)

Если командный файл не запустился, откройте два окна PowerShell в папке проекта. Выполните **npm.cmd run serve** в первом и **npm.cmd run preview** во втором.

## Работа с отчётом

- Поиск над списком рабочих наборов фильтрует проверки по имени. Можно включить одну или несколько проверок; счётчики и таблица будут рассчитаны только для них.
- Поиск над таблицей проверяет все исходные поля HTML. Дополнительные фильтры отбирают строки по статусу, рабочему состоянию и видимости знака.
- Флажки в первом столбце создают массовый выбор. Для выбранных строк доступны команды **Отработать**, **Вернуть в работу**, **Исключить**, показать или скрыть знаки. Единая кнопка **Сформировать отчёт** учитывает этот выбор.
- **В работе** означает, что коллизия требует решения. **Отработана** означает завершённую проверку. **Исключена** убирает коллизию из остатка работ, сохраняя её в исходных данных.
- **Показывать знак** управляет только видимостью в 3D и не меняет рабочее состояние.
- **Статус Navisworks** хранит исходное состояние из загруженного файла. **Группа / назначение** и **Комментарий** заполняются при обработке.
- **Столбцы** позволяет включать, переименовывать и переставлять все доступные поля коллизии и обоих объектов, включая модели, GUID и исходные свойства.
- Нажатие на снимок открывает его в отдельном увеличенном окне.

**Сохранить сессию** создаёт файл с расширением .collision360.json с исходными данными, рабочими состояниями, назначениями, комментариями и снимками. Чтобы продолжить работу, нажмите **Открыть сессию** и выберите этот файл. Плагин не подгружает прошлый отчёт из браузера автоматически.

**Сформировать отчёт** создаёт самостоятельный HTML-документ с номером коллизии, названием, проверкой, рабочим состоянием, статусом Navisworks, назначением, комментарием, координатами, снимком и данными объектов. В документе работают поиск, фильтры по состоянию и проверке, а также печать.

## Знаки и навигация в 3D

- Вертикальная ножка заканчивается в точке конфликта. Над ней расположен треугольник с белым восклицательным знаком.
- Выбранная коллизия становится жёлтой и рисуется на верхнем слое.
- Обычная коллизия красная, отработанная зелёная, исключённая серая.
- По умолчанию подпись показывается только у выбранного знака.
- Нажатие по знаку выбирает строку, плавно переводит камеру и устанавливает опорную точку в координату конфликта.
- Размер, радиус камеры, масштаб, смещения, цвета и режим подписей настраиваются в блоке **Знаки и камера**.

## Сборка и установка приложения

    npm.cmd ci
    npm.cmd run typecheck
    npm.cmd test
    npm.cmd run build

Сборка создаёт:

- статический плагин в папке **dist**;
- установочный пакет **apx/nashepo.collision360.apx**.

Пакет APX устанавливается в настольном приложении Топоматик 360 командой **Установить из файла**. В веб-версии используйте страницу установки:

https://borismoniac.github.io/CollisionFinder_NavisWorks/

Workflow **.github/workflows/pages.yml** проверяет типы и тесты, собирает плагин и публикует содержимое **dist** на GitHub Pages при каждом обновлении ветки **main**.

На 06.09.2026 проходят проверка типов, сборка и 14 тестов. Реальный пример содержит 170 проверок, 249 коллизий и 249 снимков.
